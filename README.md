# Node.js Learning Lab

A practical Node.js learning lab focused on **DevOps and production operations**.

## Goal

Learn enough Node.js to:

* Understand Node.js applications
* Run and configure applications
* Debug common issues
* Manage dependencies and processes
* Containerize with Docker
* Deploy with AWS
* Monitor and troubleshoot production applications

> **Focus:** Application awareness + Production Operations, not becoming a Node.js developer.

## Roadmap

### 01 — Fundamentals

* JavaScript basics
* Node.js CLI
* npm
* Modules
* Async/Await
* Environment variables

### 02 — Backend Basics

* HTTP
* Express.js
* Routes
* Middleware
* REST APIs

### 03 — DevOps Integration

* Configuration
* Logging
* Processes
* Testing
* Dependencies
* Troubleshooting

### 04 — Docker & Cloud

* Docker
* Nginx
* AWS
* Deployment

### 05 — Production Understanding

* Event Loop
* Scaling
* Reliability
* Observability
* Security
* Troubleshooting

## Learning Outcome

By the end, I should be able to:

```text
Read → Run → Configure → Debug
        ↓
Containerize → Deploy → Monitor → Troubleshoot
```
